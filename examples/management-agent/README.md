# Management agent installation example

This directory contains an example npm client installation manifest and lockfile. Maintained CLI
and MCP source code lives in [tools/document-intake-agent](../../tools/document-intake-agent/).

The `management-agent` path shown in customer setup instructions is a user-chosen installation
directory; it is independent of this repository layout. Existing local installations at that path
continue to work. Credentials and `node_modules` must never be committed.
