## Review scenarios

1. Connected tools: latest-document request selects document_list with bounded results.
2. Unconnected hosted client: skill describes missing transport; does not invent a connector URL.
3. PDF summary request: metadata-only limitation is explicit.
4. Expired key: secure replacement instruction, not a request to paste secrets in chat.
5. Public prompt: only configured website origin and public skill path; no issued key interpolation.

These are document review scenarios, not claims of live model evaluation across AI products.

## Remaining decision

Remote MCP and OAuth consent are a separate implementation slice. Select authorization provider, client compatibility, grant lifetime and revocation/refresh design before implementation. A public skill cannot suppress another product's security policy or replace authorization. Production location and rollback details are recorded outside the repository on the approved VM.
